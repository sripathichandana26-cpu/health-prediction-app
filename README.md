# Health Prediction Application

## Overview

A Streamlit-based healthcare application that predicts patient health risk and generates AI-powered health remarks using Google Gemini.

## Features

* Patient Registration
* Health Risk Prediction
* AI Generated Health Remarks
* SQLite Database Storage
* Dashboard Metrics
* Data Validation

## Technology Stack

* Python
* Streamlit
* SQLite
* Pandas
* Google Gemini API

## Run Project

Install requirements:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Inputs

* Full Name
* Date of Birth
* Email
* Glucose
* Haemoglobin
* Cholesterol

## Outputs

* Risk Prediction
* AI Health Remark
* Patient Records Dashboard
